# 買い替えヒアリングシート(パソコン/スマートフォン/タブレット/携帯料金見直し)

お客様にスマホやPCから入力してもらい、
回答を **Googleスプレッドシート** と **Gmail通知** で受け取るための
Webフォームです。

## できること

### お客様の入力
- パソコン・スマートフォン・タブレット・携帯料金見直しのヒアリングシートを切り替えて表示
- 送信後に「携帯料金・Wi-Fiの見直し」をおすすめし、料金見直しのヒアリングシートへ案内
  (お名前とメールアドレスだけ引き継ぎ)
  (契約・支払い・データ・通話・電波・ポイント・自宅のネットまで聞き、提案の精度を上げる)
- 「かんたん版(約1分)」と「しっかり版(約3分)」を選べる
- 答えによって質問を出し分け(例:デスクトップを選ぶと、ノートPC用の質問を隠す)
- 今使っているメーカーを選ぶと、機種(シリーズ)・容量などを追加で質問
- 「一緒に購入したいもの」で選んだ商品ごとに、追加の質問を表示
- 用語の「?」説明、文字を大きくするボタン
- 今の機種の写真を3枚まで添付(自動で縮小)
- 必須項目の進み具合バー、送信前の確認画面、入力途中で閉じるときの確認
- 再読み込みや再入力のときは、前の入力内容を残さない(個人情報保護のため)

### 送信の確実さと安全
- 送信後に「本当に届いたか」を確認し、届かなかったときは再送信できる
- 同じ回答の二重登録を防止
- いたずら送信対策(見えない入力欄・送信時間・件数の上限・任意で Cloudflare Turnstile)
- 通知先メールアドレスは、GitHub ではなく Google 側にだけ保存

### お客様への対応
- 受付番号の発行、「このあとの流れ」の表示、受付完了メール
- 回答の控えを印刷・PDFで保存

### お店の運用(Googleスプレッドシート)
- 通知メールに「提案のヒント」を自動で付ける
- 対応状況のプルダウン(未対応は赤、成約は緑)
- 24時間以上未対応の回答を、毎朝メールでお知らせ
- 「集計」シート(回答数・成約率・用途や予算の分布)を毎朝更新
- 回答から「見積もりのたたき台」を作成(単価は「価格表」シートから自動入力)

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | フォーム画面 |
| `questions.js` | 質問項目の定義(ここを編集すると質問を変えられます) |
| `models.js` | 「現在お使いの機種」でメーカーを選んだときに出る、機種・容量などの質問 |
| `accessories.js` | 「一緒に購入したいもの」の商品と、選んだときに出る追加質問 |
| `config.js` | 送信先URL・店舗名・連絡の目安などの設定 |
| `gas/Code.gs` | 回答を受け取る Google Apps Script |
| `docs/SETUP.md` | 設置手順 |

## はじめに

[docs/SETUP.md](docs/SETUP.md) の手順に沿って設定してください(約15分)。
