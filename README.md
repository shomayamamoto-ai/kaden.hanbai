# 買い替えヒアリングシート(パソコン/スマートフォン)

お客様にスマホやPCから入力してもらい、
回答を **Googleスプレッドシート** と **Gmail通知** で受け取るための
Webフォームです。

## できること

- パソコン用・スマートフォン用のヒアリングシートを切り替えて表示
- スマホでも入力しやすいレスポンシブ表示
- 提案・連絡に欠かせない項目の必須チェック
- 送信された回答をスプレッドシートに記録し、管理者へメール通知
- 入力しやすくする仕組み
  - 必須項目の回答状況がわかる進み具合バー
  - 再読み込みや再入力のときは、前の入力内容を残さない(個人情報保護のため)
  - 送信前の確認画面
- 「一緒に購入したいもの」で選んだ商品ごとに、追加の質問を表示
- 送信後に安心してもらう仕組み
  - 受付番号の発行
  - 「このあとの流れ」と連絡の目安の表示
  - お客様への受付完了メール(受付番号・回答内容つき)
  - 回答の控えを印刷・PDFで保存

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | フォーム画面 |
| `questions.js` | 質問項目の定義(ここを編集すると質問を変えられます) |
| `accessories.js` | 「一緒に購入したいもの」の商品と、選んだときに出る追加質問 |
| `config.js` | 送信先URL・店舗名の設定 |
| `gas/Code.gs` | 回答を受け取る Google Apps Script |
| `docs/SETUP.md` | 設置手順 |

## はじめに

[docs/SETUP.md](docs/SETUP.md) の手順に沿って設定してください(約15分)。
