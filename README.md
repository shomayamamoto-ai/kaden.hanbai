# 買い替えヒアリングシート(パソコン/スマートフォン)

お客様にスマホやPCから入力してもらい、
回答を **Googleスプレッドシート** と **Gmail通知** で受け取るための
Webフォームです。

## できること

- パソコン用・スマートフォン用のヒアリングシートを切り替えて表示
- スマホでも入力しやすいレスポンシブ表示
- 必須項目(お名前・メールアドレス)の入力チェック
- 送信された回答をスプレッドシートに記録し、管理者へメール通知
- 「印刷・PDFで保存」で紙のヒアリングシートとしても利用可能

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | フォーム画面 |
| `questions.js` | 質問項目の定義(ここを編集すると質問を変えられます) |
| `config.js` | 送信先URL・店舗名の設定 |
| `gas/Code.gs` | 回答を受け取る Google Apps Script |
| `docs/SETUP.md` | 設置手順 |

## はじめに

[docs/SETUP.md](docs/SETUP.md) の手順に沿って設定してください(約15分)。
